Name: Matthew Higgins
Application: Project Manager

Usage: This application can manage projects. You can create accounts and login to accounts. When creating a project, a registered account is needed along with a project name, description, and status. Project Memberships may also be viewed. You can add and remove accounts after the project has been created. The Project Lead may not be removed.

Instructions: 
  Sign Up:
    Type a first and last name, a username and a password, then press Sign Up button. Duplicate Usernames are not allowed. All fields must be populated.
  Log In:
    provide the username and password in the correct fields, then press Login button. username must be one that has already been created in "Signup". Password must be the password associated to that account.
  Create Project:
    Must provide a name, description, status, and Lead project member. Can have multiple projects with same name and can have same leader on multiple projects. Cannot have same name and leader on more than ONE project.
  Project Memberships:
    Select a project from the dropdown. It will show a list of the members. Select a member from the other dropdown and press add member to add that account to the project. Press Delete member to remove that account         from the project.

Problems and Incomplete Features: Add and Delete member buttons pop up before an account is selected in "Project Memberships".
